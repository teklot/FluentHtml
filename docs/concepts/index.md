# Packages

FluentHtml is split into focused packages. Install only what you need.

| Package | Description |
|---------|-------------|
| [Core (FluentHtml)](core.md) | HTML elements, Node hierarchy, Components, Rendering |
| [HTTP](http.md) | HTTP layer integration |
| [HTMX](htmx.md) | HTMX attribute extensions |
| [Bootstrap](bootstrap.md) | Bootstrap components and CSS helpers |
| [Forms](forms.md) | Strongly-typed form helpers |
| [Validation](validation.md) | Validation components |
